# RSLLM

## 历史报表与记录（完整入口）

RSLLM 记录入口统一如下：

- `docs/HISTORY_REPORT_INDEX.md`：记录总索引（推荐从这里开始）
- `docs/HISTORICAL_CHANGELOG_REPORT.md`：变更历史总报表（提案/依赖/里程碑）
- `docs/RELEASE_DELIVERY_AUDIT_REPORT.md`：发布与交付记录报表（批次/验证/回滚）
- `docs/OPERATION_RECORDS_REPORT.md`：运行与审计记录报表（任务/事件/通知/统计）
- `docs/RECORD_COMPLETENESS_MATRIX.md`：记录完整性矩阵
- `docs/API_GUIDE.md`：运行记录相关 API 入口
- `docs/IMPLEMENTATION_SUMMARY.md`：专题实现总结

## 当前记录体系覆盖维度

- 变更提案记录：`changes/*/proposal.md`
- 技术设计记录：`changes/*/design.md`
- 执行任务记录：`changes/*/tasks.md`
- 一致性审计记录：`changes/consistency-verification.md`
- API 运行记录接口：`docs/API_GUIDE.md`

> 建议后续每次新增变更时，同步更新上述索引与历史报表，确保记录持续完整。
